# janet-skills

A [pi agent skill](https://skills.sh/) for writing idiomatic Janet code.

## Usage

Install with the skills CLI:

```bash
npx skills add <your-github-username>/janet-skills
```

After installation, the skill will be available to pi when working with `.janet` files.

## Contents

- `janet/SKILL.md` — the skill definition covering functional patterns, performance tradeoffs, common gotchas, data structure idioms, PEG parsing, and Janet-specific pitfalls.
